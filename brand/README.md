## PWA/앱 아이콘 공식 사양
- **배경**: #00c471 그린 **통짜** 바탕 (중간층 흰 판 **없음**).
- **로고**: `srm-logo-master.png` 를 **무변형**으로 아이콘 폭 **65%** 중앙 배치(PWA).
- **금지**: 로고 재창작 · 서체 변형 · 색 치환(흰색화 등) · 배경 구조 변경.

## 네이티브 스플래시/런처 배율 (원형 세이프존 실측)
- Android12 스플래시 아이콘은 **캔버스의 2/3 지름 원형**으로 클립된다. 로고가 그 안에 들어가야 잎이 안 잘림.
- 현행 와이드 로고(1.863:1) 실측: 잎끝 `maxR_norm=0.566` → 한계 폭배율 `(1/3)/0.566=58.9%`.
  **스플래시 58% 확정**(`SPLASH_LOGOP`, 잎끝이 세이프존의 98.3%·여유 1.7%, 실물 확인 OK — 한계 근접이라 이 이상 금지),
  **런처 55%**(`LAUNCHER_LOGOP`).
- **로고 형태(종횡비)가 바뀌면 배율을 반드시 재계산**: `f_max = cw/(3·Dmax)` (Dmax=중심~최원불투명점).
  `node brand/generate-android-icons.cjs [배율]` 로 스플래시 배율 인자 조정 가능.

## 마스터 파일
- `srm-logo-master.png` — 아이콘 파생의 **원본**(투명 정사각, 컨텐츠 폭 꽉참 → 스크립트 LOGOP=폭배율 직결).
  이 파일에서만 파생한다.

## 재생성 / 사이즈 추가
shop 루트에서:
```
node brand/generate-pwa-icons.cjs
```
→ `public/icons/icon-<size>.png` (72~512) + `public/logo192.png` + `public/logo512.png` 생성.
사이즈 추가는 `generate-pwa-icons.cjs`의 `SIZES` 배열에만 추가한다(**로고 재창작 금지**, 이 스크립트로만 파생).

## 주의
`public/srm-logo.svg` 는 벡터가 아니라 base64 PNG를 감싼 **래스터**라 SVG fill 색치환이 불가하다.
색/형태 변형은 하지 않는다(사양상 원본 무변형).
