> 둘이 다르면 목업이 맞다 — 고칠 때는 **둘을 같이** 고친다.

## 4. 규칙(목업에서 지킨 것)

1. **상태바 위·탭바 아래 회색 띠 없음** — 화면 바탕(`--bg`)이 상태바 뒤까지 그대로 이어진다.
   안전영역은 **한 번만** 더한다(지금 앱은 `.App` 과 `.header` 가 두 번 더한다 — SHOP_SCREENS 2-③).
2. **확인창은 전부 커스텀 하나**(S34 모양). `window.confirm/alert` 금지. 취소는 왼쪽, 위험 동작은 빨강.
3. **규격은 상품이 나오는 모든 곳에**(CLAUDE.md 「규격은 필수 항목이다」).
4. **태블릿(화면 폭 700px 이상)**: 상품 2열 → 4열, 장바구니·주문서는 「목록 | 결제」 두 칸, 상세는 「사진 | 정보」 두 칸,
   시트는 가운데 카드(최대 560px). 탭바는 그대로 아래(지금 앱은 ≥768 에서 탭바를 숨기고 상단 메뉴 — 거기에 **검색이 없다**, F9).
5. **하단 탭바는 5칸 — 홈 · 검색 · 장바구니 · 주문내역 · 마이**(결정 6). 찜은 마이 안(「찜한 상품」 줄 → S19).
   폰·태블릿 **같은 하단 탭바**(태블릿 상단 메뉴 없앰 — F9 해결). 켜진 탭: 아이콘 `--brand`, 글자 `--brand-strong`.
6. **헤더 로고는 SRM 로고 이미지**(`C:/srmart/brand/shop/`, 높이 28px) — 외부 글꼴 손글씨를 쓰지 않는다(F7).
