## 정할 것
1. **「입력해 주세요」 → 「넣어 주세요」** 로 통일할지(고친 안 전체가 이 가정). 그대로 두시면 띄어쓰기·느낌표만 맞춥니다.
2. 로그인 칸 이름을 **「아이디 또는 이메일」** 로 바꿀지 — 지시 4로 이메일을 넣은 회원은 이메일로도 로그인됩니다.
3. 3단계 [선택] 지점 통합 동의의 긴 설명을 **[보기] 전문으로 옮길지**(목업 모양) — 동의 범위를 말하는 글이라 자문 확인이 필요합니다.
4. 서버 오류 문구(로그인 잠김 · 사용 중지 · 비밀번호 규칙 · 문자 인증)도 같이 바꿀지 — 백엔드 문구라 POS·어드민 로그인과 겹치는 것이 있는지 반영 때 셉니다.
