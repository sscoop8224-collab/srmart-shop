**다르게 둔 곳**

1. **최근 본 상품의 「편집」(지우기)이 없다** — 서버에 최근 본 기록을 지우는 길이 없다. 🔸 넣으려면 백엔드 경로가 먼저다(대표님 결정 대기).
2. **가격은 지금 매장 상품 목록에서** — 서버 응답에 가격·재고가 없다(전 매장 공통 칸만). 그래서 **지금 매장에서 팔지 않는 상품은 카드로 못 보여 빼고**, 아래에 「지금 매장에서 팔지 않는 상품 N개는 빼고 보여 드려요」라고 말한다(조용히 빠지면 기록이 사라진 줄 안다).
3. **카드의 행사 딱지(2+1)** — 목업 카드에는 있지만 앱은 홈·찜과 같이 **「행사중」 필터에서만** 행사 값을 붙인다(카드 규칙은 홈과 같게 둠 · 이 화면만 따로 붙이지 않았다).
4. **리뷰 상품의 그림·규격** — 서버 응답은 상품 이름뿐이라 그림·규격은 지금 매장 상품 목록에서 찾는다. 이 매장에 없는 상품이면 상자 아이콘 + 이름만(규격 없음). 🔸 서버가 `spec`·`image` 를 같이 주면 늘 나온다.
5. **리뷰 날짜** — 목업 그림에는 없지만 목업 메모(「상품·별점·내용·날짜」)대로 별점 옆에 넣었다. 기기 날짜로 찍는다(UTC 앞 10자를 자르지 않는다).
6. **관리자가 가린 리뷰** — 「관리자가 가린 리뷰예요 — 상품 화면에는 보이지 않아요」 한 줄을 붙인다(목업에 없는 상태 · 손님이 왜 안 보이는지 모르게 두지 않는다).
