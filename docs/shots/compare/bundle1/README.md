## 목업과 다르게 둔 곳 — 목록

1. **종(공지) 위 빨간 점을 그리지 않았다.** 읽지 않은 공지 수를 주는 서버 자료가 없다. 자료가 생기면 `AppHeader` 의 `.dot` 하나로 된다.
2. **토스트 문구는 그대로다** — 앱 「농심 메론킥이(가) 장바구니에 담겼어요! 🛒」 · 목업 「농심 메론킥 60g을 장바구니에 담았어요」.
   모양(바탕·아이콘·위치·탭바 바로 위)만 옮겼다. 문구는 `SHOP_PROGRESS.md` 「앱 반영 때 같이 바꿀 문구」 표대로 3번 묶음(담기)에서 바꾼다.
   아이콘은 문구로 고른다(「담겼/담았」 → 확인 표시, 나머지 → 경고 표시).
3. **불러오는 중(S43)** — 목업은 상세 화면 뼈대(뒤로 줄 + 탭바)다. 앱은 어느 화면이든 같은 뼈대 하나를 헤더·탭바 사이에 그린다
   (어느 화면 조각을 받는 중인지 앱이 미리 알 수 없다). 예전의 **진한 초록 전체 화면**과 「불러오는 중…」 글자는 없앴다.
4. **확인창이 뜨는 자리** — 목업은 장바구니 위, 앱은 지금 보던 화면(홈) 위에 뜬다. 앱은 로그인 안 한 손님이 장바구니 탭을 누르면
   장바구니로 가지 않고 그 자리에서 안내한다. 「확인」을 누르면 로그인 화면으로 간다(예전엔 안내와 동시에 로그인 화면으로 넘어갔다).
5. **매장 칩(왕길점 ▾)** — 로그인 안 한 손님만 눌러서 매장을 바꾼다(지금 있는 점포 선택 창). 회원·대표님 계정은 이름만 보인다
   (회원 매장 바꾸기는 2번 묶음 S07 점포 선택, 대표님은 지금처럼 미리보기 띠의 고르기).
6. **AI 상담 창 모양은 그대로다** — 떠 있는 단추만 없애고 헤더 아이콘으로 열게 했다. 창은 탭바 바로 위에 뜬다. 창 모양은 6번 묶음(S37)에서.
7. **헤더의 로그아웃·사용자 이름을 뺐다**(결정 11 — 로그아웃은 마이 맨 아래). 마이 화면의 로그아웃 줄은 그대로 있다.
8. **찜 탭을 뺐다**(결정 6). 마이 안 「찜한 상품」·「찜 목록」 줄로 간다. 마이 화면 정리는 5번 묶음.
9. **화면 모드(자동·밝게·어둡게)** — 마이 화면의 옛 다크 모드 카드 자리에 목업의 세그먼트를 넣었다. 마이 화면의 다른 카드는 5번 묶음까지 옛 모양이다.
   옛 저장값(`srmart_dark_manual`·`srmart_dark_mode`)은 새 값(`srmart_theme_mode`)으로 옮긴다 — 수동으로 골라 둔 손님의 선택이 유지된다.
10. **옛 화면들의 색** — 묶음 1 은 토큰과 공용 부품만 옮겼다. 홈·상세·장바구니 같은 화면 안쪽은 여전히 옛 색(`--white`·`--gray-*` · 직접 쓴 #색)이다.
    옛 이름의 값은 예전과 똑같이 두었다(밝게·어둡게 모두) — 묶음 1 때문에 옛 화면 색이 바뀌지 않게.
    단, 이름이 겹치는 `--bg`·`--card`·`--text`·`--sep`·`--danger`·`--warning`·`--info` 는 목업 값이 됐다(어둡게의 `--bg` 가 #242424 → #000000 등).
11. **글꼴** — 목업과 같은 Pretendard 세 굵기(`src/assets/fonts`, OTF 4.7MB)를 넣었다. 처음엔 빼고 옮겼더니 같은 글자 폭이
    60.3px(목업) ↔ 66px(앱)로 달랐다. 🔴 크기 결정 대기: WOFF2·한글 2,350자로 줄이면 약 1/5 로 준다(도구 설치가 필요해 밤에는 안 했다).
12. **`<html lang="ko">`** — 예전엔 `en` 이었다. 브라우저가 한글 대체 글꼴을 다르게 골라 글자 간격이 벌어졌다.

## 이 비교에서 찾아 고친 것

- **오프라인 화면이 인터넷이 끊기면 안 떴다.** 오프라인 화면을 「필요할 때 받는 조각」으로 떼어 두어서, 끊긴 순간 그 조각을 받으러 가다 실패했다
  (`Loading chunk 824 failed`). 첫 묶음에 같이 넣었다. 🔴 **운영 앱에도 있는 결함이다**(서비스워커가 그 조각을 미리 받아 두지 않았다면).
- 부품 초기화 규칙의 우선순위가 높아 매장 칩 바탕이 사라지고 탭 글자가 흰색이 됐다 → `:where()` 로 0 으로 낮췄다.
