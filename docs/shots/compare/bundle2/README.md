## 목업과 다르게 둔 곳 — 목록

1. **행사 딱지(2+1)·할인가(30%)는 「행사상품」 칩을 골랐을 때만 보인다.** 목업은 전체 목록에도 보인다.
   🔴 일부러 안 옮겼다 — 장바구니는 지금 `price`(정가)로 계산한다. 전체 목록에 할인가를 보여 주면 **화면에 보인 값과 장바구니 값이 달라진다.**
   행사가가 장바구니·주문에 어떻게 들어가는지 확인한 뒤(3번 묶음) 같이 옮긴다 — 대표님 확인 항목.
2. **사진 없는 상품** — 목업은 이모지 + 연한 색 바탕, 앱은 지금처럼 분류 사진(외부 주소). 사진 비교에서는 외부 주소를 막아 빈 칸으로 찍힌다.
3. **배너** — 관리자가 고른 색(`bg`)·사진(`image_url`)을 그대로 쓴다(목업은 토큰 초록 한 가지). 사진 배너는 글자가 읽히게 왼쪽을 어둡게 덮는다(목업에 없음).
   여러 장이면 지금처럼 3초마다 넘기고 손으로 밀어도 넘어간다. 아래 점 대신 목업의 「1 / 2」.
   부품 비교(P05N)는 색을 빼고(토큰 초록으로) 모양만 잰다.
4. **분류 칩 2·3단** — 목업은 한 줄. 앱은 큰 분류를 고르면 중·소 분류 칩 줄이 작은 칩(`.chip.sm`)으로 이어진다(지금 기능 유지).
5. **정렬** — 목업 「기본순 ▾」 모양 그대로, 누르면 휴대폰 기본 고르기 창이 뜬다(투명한 `select` 를 덮었다). 고르는 시트(S43 류)는 다음 묶음.
6. **배송 한 줄 오른쪽 작은 글자** — 오늘 도착은 서버의 `sub`(「오늘 오후 4시 출발」), 마감 후는 서버 `start` 로 「내일 오후 4시 출발」.
   당일배송 불가·배송 휴무는 목업처럼 매장 이름.
7. **「가입하기」** — 로그인 화면을 **가입 모드로** 연다(`Login` 에 `initialMode` 추가). 가입 화면 자체는 5번 묶음(P04).
8. **주류 카드** — 목업처럼 본인확인 전에는 가격·담기 대신 「🔒 19세 이상 본인확인 필요」. 「매장 픽업」 딱지는 픽업 주문이 앱에 생길 때(3번 묶음) 붙인다.
   담기는 지금처럼 `addToCart` 가 한 번 더 막는다(화면에서만 숨기지 않는다).
9. **검색 결과 줄의 사진** — 검색 응답(`/api/search`)에는 사진이 없다. 홈이 받아 둔 같은 매장 상품이 있으면 그 사진·품절·행사 표시를 쓴다.
10. **검색의 「인기 검색어」** — 목업처럼 검색 뒤에도 결과 위에 남는다.
11. **검색 화면에는 홈 헤더가 없다**(검색창이 헤더 — 목업 S06). 다른 화면은 각 묶음까지 지금 헤더.
12. **점포 선택(S30)** — 가운데 창 + 고르기 칸 + 「둘러보기 시작」 → 목업의 아래에서 올라오는 시트, 줄을 누르면 바로 그 매장.
    태블릿(700 이상)은 가운데 카드. 가짜 응답의 매장은 3곳이라 목업(4곳)보다 한 줄 적다.
13. **매장 미리보기 띠(S02)** — 목업의 주황 알림 띠 + 매장 칩. 칩을 누르면 휴대폰 기본 고르기 창. 띠는 지금처럼 **모든 화면**에 보인다(목업은 홈만 그렸다 — 사장님이 미리보기 중임을 놓치지 않게 일부러 둔 것이라 유지).
14. **옛 바닥글(© …)** — 홈·검색에서는 안 그린다(홈은 사업자 정보 아래 목업 바닥글). 다른 화면은 각 묶음까지 그대로.

## 이 묶음에서 찾아 고친 것

- **헤더의 매장 이름 앞에 공백이 남았다** — 묶음 1 에서 정규식의 `\` 가 빠져(`/^에스알마트s*/`) 「에스알마트」만 지우고 공백이 남았다. 고쳤다.
- **검색에서 엔터를 친 뒤 추천 검색어가 결과를 덮었다** — 0.2초 늦게 오는 추천 목록이 검색 뒤에 열렸다. 늦게 온 추천은 버린다.
- **검색 정렬·분류·재고 칸을 바꾸면 바꾸기 전 값으로 다시 찾았다** — 새 값으로 찾는다.
